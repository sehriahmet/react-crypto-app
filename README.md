# React Crypto App

A cryptocurrency price tracking app built with React. This app displays the price history of various cryptocurrencies, as well as the current price and percentage change.

### Live Demo
Check out the live version of the app here: [React Crypto App](https://sehriahmet.github.io/react-crypto-app)

## Features

- Cryptocurrency price tracking.
- Historical price chart using Chart.js.
- Display of current price and percentage change.
- Responsive design, adaptable to different screen sizes.
- Built with Ant Design for modern UI components.

## Tech Stack

- **React**: A JavaScript library for building user interfaces.
- **Chart.js**: For visualizing cryptocurrency price data.
- **Ant Design**: UI components for styling.
- **Redux**: For state management (if applicable).
- **Axios/Fetch**: For making API requests to fetch crypto data.
